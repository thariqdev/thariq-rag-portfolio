# FundsApp — Mutual Fund Investment Platform

## Overview
FundsApp is a fintech and wealth-management application.
Users sign up, complete KYC, get a risk profile, and then invest, including through SIPs.
Thariq worked on it at Evoqins Pvt Ltd.

## Thariq's role
Thariq was a Software Engineer on FundsApp at Evoqins Pvt Ltd.
He worked on the backend only, using Python, FastAPI, SQLAlchemy and PostgreSQL.
He built and worked with 15+ REST APIs.
He worked on onboarding, authentication, KYC, investments and SIP management.
He did not work on the FundsApp frontend. His frontend work at Evoqins was on Rudo and Rayi.

## Tech stack
The frontend uses React and Next.js. Thariq did not work on it.
The backend uses Python and FastAPI.
The database is PostgreSQL, accessed through SQLAlchemy.
Authentication uses JWT.
Thariq tested APIs with Postman and Swagger (OpenAPI).

## Features
FundsApp covers partner and customer onboarding.
It covers authentication, KYC, investments and SIP management.
It also has risk profiling, client management, account lifecycle and account closure.
It has notification preferences.

## Security
Authentication is JWT-based.
FundsApp also has MPIN-based security workflows.

## SIPs
SIP means Systematic Investment Plan.
It is a fixed amount invested at regular intervals.
